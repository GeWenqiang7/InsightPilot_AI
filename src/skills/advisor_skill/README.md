# Advisor Skill

`advisor_skill` is dedicated to **strategy generation + constraint optimization**.

Inputs:
- `model_result`
- `evaluation_result`
- optional `constraints`, `user_query`, `rag_context`, `kg_context`

Outputs:
- `strategy_plan`
- `constraint_optimization`
- `scenario_options` (3-5)
- `rag_kg_hooks`
- `advisor_for_llm`
