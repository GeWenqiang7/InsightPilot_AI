# LLM & CTR Analysis Project

This project includes:

- OpenAI API usage and token analysis
- CTR (Click-Through Rate) prediction dataset analysis (Alibaba Tianchi)

## Modules

### 1. CTR Analysis
- Dataset: Alibaba Display Ad Click Dataset

### 2. OpenAI API Usage

- API integration examples
