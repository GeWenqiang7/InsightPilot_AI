# 🚀 专题1：Transformer（模型基础）

## 🧠 是什么？

> Transformer 是大语言模型（GPT、DeepSeek等）的核心架构

核心机制：

* Self-Attention（自注意力）
* Token序列建模

---

## ⚙️ 功能

* 理解上下文
* 生成文本
* 长距离依赖建模

---

## 🧪 如何运用？

👉 不需要自己训练，但要理解：

* token是如何输入的
* context window（上下文长度）
* attention影响输出质量

---

## 💼 产品价值

* 优化Prompt（减少token浪费）
* 理解为什么模型“幻觉”
* 控制成本（token优化）

---

# 🚀 专题2：RAG（Retrieval-Augmented Generation）

## 🧠 是什么？

> **让LLM“查资料再回答”**

```text
用户问题
→ 检索知识库
→ 拼接到Prompt
→ LLM回答
```

---

## ⚙️ 功能

* 解决“幻觉”
* 使用私有数据
* 实时更新知识

---

## 🧪 如何实现？

技术栈：

```text
Embedding + 向量数据库 + LLM
```

流程：

1. 文档 → embedding
2. 存入向量库（FAISS / Pinecone）
3. 查询时检索相关内容
4. 拼接到prompt

---

## 💼 产品价值

* 企业知识问答系统
* 文档助手（PDF / Excel）
* 客服机器人

---

# 🚀 专题4：微调（Fine-tuning）

## 🧠 是什么？

> 用你的数据“重新训练模型的一部分”

---

## ⚙️ 功能

* 让模型更懂你的业务
* 固定输出风格
* 提升准确性

---

## 🧪 如何做？

```text
数据（input → output）
→ 训练
→ 得到定制模型
```

---

## 💼 产品价值

* 医疗数据分析

## 🧪 技术点

---

## 💼 产品价值

* 本地运行LLM
* 边缘设备部署
* 降低服务器成本
